# ConstructNH

Весь код бэкенда и админки, а также связанные с ними файлы размещай в папке `backend/`.

## Graphify

Если `backend/graphify-out/graph.json` доступен, используй Graphify для навигации по связям в коде бэкенда. Из папки `backend/` запусти `graphify query "<вопрос>"` или `.graphify-tools/bin/graphify query "<вопрос>"`, если CLI установлен локально. Сверяй вывод с исходниками, особенно после изменений. Команда пересборки описана в `backend/README.md`.
